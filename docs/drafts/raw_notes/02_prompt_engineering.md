# 1. What is Prompt Engineering?

## Definition

Prompt Engineering is the process of designing instructions that guide an LLM toward desired behavior and outputs.

Think of a prompt as:

```text
A Program Written in Natural Language
```

---

## Why Does Prompt Engineering Exist?

LLMs are probabilistic systems.

Small prompt changes can produce significantly different outputs.

Example:

Prompt A:

```text
Explain Python.
```

Output:

```text
Generic explanation
```

Prompt B:

```text
Explain Python to a beginner.

Include:
- What it is
- Why it is popular
- Example code
- Common mistakes

Limit to 200 words.
```

Output:

```text
Structured and focused explanation
```

---

## Key Principle

Bad Prompt:

```text
Vague Input
 ↓
Vague Output
```

Good Prompt:

```text
Precise Input
 ↓
Predictable Output
```

# 3. System Prompt

## Definition

A high-priority instruction that defines the model's behavior.

---

## Example

```text
You are a senior software architect.
```

---

## Why Use It?

Without a system prompt:

```text
Model behavior is generic.
```

With a system prompt:

```text
Behavior becomes specialized.
```

---

## Examples

### Instructor

```text
You are a senior Python instructor.
```

---

### Customer Support

```text
You are a customer support representative.

Always be polite and concise.
```

---

### RetailOps Project

```text
You are RetailOps AI Assistant.

Do not invent company policy.
Use available tools when necessary.
```

---

## Pros

```text
Consistent behavior
Better reliability
Easier control
```

---

## Cons

```text
Poorly written prompts create poor behavior
Long prompts consume context
```

---

# 4. User Prompt

## Definition

The current request from the user.

Example:

```text
How many vacation days do employees receive?
```

---

## Why It Matters

The quality of the user's prompt strongly influences the response.

---

# 5. Assistant Message

## Definition

Previous responses generated by the model.

Used for:

```text
Conversation continuity
Memory
Context preservation
```

---

## Example

```text
User:
What is Python?

Assistant:
Python is a programming language.

User:
Why is it popular?
```

The model understands:

```text
Why is Python popular?
```

because previous messages are included.

---

# 6. Zero-Shot Prompting

## Definition

Giving instructions without examples.

---

## Example

```text
Classify the sentiment:

"I love this product."
```

Output:

```text
Positive
```

---

## Pros

```text
Simple
Fast
Low token usage
```

---

## Cons

```text
Less reliable for complex tasks
```

---

## When To Use

```text
Simple classification
Basic summarization
General questions
```

---

# 7. Few-Shot Prompting

## Definition

Providing examples before asking the model to perform a task.

---

## Example

```text
Input: Cat
Output: Animal

Input: Apple
Output: Fruit

Input: Car
Output:
```

Model:

```text
Vehicle
```

---

## Why It Works

LLMs are pattern-completion systems.

Examples often teach behavior better than instructions.

---

## Pros

```text
Higher accuracy
More consistent formatting
```

---

## Cons

```text
Consumes context
Can become expensive
```

---

## When To Use

```text
Classification
Extraction
Complex formatting
```

---

# 8. Chain of Thought Prompting

## Definition

Encouraging the model to reason step by step.

---

## Example

Bad:

```text
What is 17 × 23?
```

Better:

```text
Solve step by step.
```

---

## Why Use It?

Improves reasoning quality.

---

## Pros

```text
Better reasoning
Improved accuracy
```

---

## Cons

```text
More tokens
Higher latency
```

---

## Production Note

Modern reasoning models often perform internal reasoning automatically.

Use explicit reasoning prompts when needed.

---

# 9. Structured Prompting

## Definition

Designing prompts that produce predictable machine-readable outputs.

---

## Example

Bad:

```text
Summarize this document.
```

Output:

```text
Unpredictable text
```

---

Good:

```text
Return JSON:

{
  "summary": "",
  "risks": [],
  "recommendations": []
}
```

Output:

```json
{
  "summary": "...",
  "risks": [...],
  "recommendations": [...]
}
```

---

## Why Use It?

Applications need structured data.

---

## Use Cases

```text
Extraction
Classification
Routing
Workflow Automation
```

---

# 10. Prompt Templates

## Definition

Reusable prompts with variables.

---

## Problem Without Templates

Bad:

```python
topic = "Decorators"

prompt = f"""
Explain {topic}
"""
```

Hard to maintain.

---

## LangChain Solution

```python
from langchain_core.prompts import ChatPromptTemplate

prompt = ChatPromptTemplate.from_template(
    """
    Explain {topic}
    """
)
```

---

## Why Use Templates?

```text
Reusable
Maintainable
Versionable
Testable
```

---

## Example

```python
prompt = ChatPromptTemplate.from_template(
    """
    Explain {topic}
    for a {level} developer.
    """
)

prompt.invoke({
    "topic": "Decorators",
    "level": "Beginner"
})
```

---

# 11. ChatPromptTemplate

Most production systems use:

```python
ChatPromptTemplate.from_messages()
```

Example:

```python
prompt = ChatPromptTemplate.from_messages([
    (
        "system",
        "You are a Python instructor."
    ),
    (
        "human",
        "{question}"
    )
])
```

---

## Why?

Modern chat models operate on messages, not plain text.

# 13. RAG Prompt Pattern

Used in our RetailOps project.

Example:

```text
Answer using only the provided context.

If the answer is not present:
"I don't know based on the available documents."
```

---

## Why?

Prevents hallucinations.

---

## Production Benefits

```text
Grounded answers
Reduced hallucinations
More trust
```

---

Used for routing.

Example:

```text

```

---

## Why?

Allows the model to act as a classifier.

---

## Used In RetailOps

 ↓

# 15. Prompt Versioning

## Definition

Tracking prompt changes over time.

---

## Why?

Prompts are application logic.

Changes affect behavior.

---

## Example

```text
v1
Basic Prompt

v2
Added source citations

v3
Added confidence scoring
```

---

## Production Recommendation

Store prompts in:

```text
prompts.py
```

or

```text
prompt files
```

instead of hardcoding them throughout the application.

---

# 17. Common Prompt Engineering Mistakes

---

## Mistake 1

Too vague.

Bad:

```text
Explain Python.
```

---

Better:

```text
Explain Python to a beginner.

Include:
- Definition
- Example
- Use Cases
```

---

## Mistake 2

No output format.

Bad:

```text
Summarize this.
```

---

Better:

```text
Return:

Summary:
Risks:
Recommendations:
```

---

## Mistake 3

Not constraining hallucinations.

Bad:

```text
Answer the question.
```

---

Better:

```text
Answer only using provided context.
```

---

## Mistake 4

Prompt duplication.

Store prompts in reusable templates.
